# ENTERPRIZE RM2025 雷达站开源第一视角

### 文件结构:
`<name>.mp4`: 视频文件 

`<name>_timestamp.json`: 时间戳文件(如果你有需要的话)

- `start_timestamp`：第一帧的绝对时间（毫秒级 Unix 时间戳，UTC 基准）。
- `timezone_offset_hours`：本地时区偏移，8 表示北京时间（UTC+8）。
- `total_frames`：总共提取的帧数。
- `offsets`：每帧相对于第一帧的毫秒级时间偏移，用于计算每一帧的准确时间。
     

> 任意帧的绝对时间 = `start_timestamp + offsets[i]`
